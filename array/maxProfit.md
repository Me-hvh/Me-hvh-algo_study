# 买卖股票的最佳时机

**Difficulty:** Easy

**Tags:** 数组, 动态规划

## 题目描述

给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择  **某一天**  买入这只股票，并选择在  **未来的某一个不同的日子**  卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

## 示例 1：

```
输入：[7,1,5,3,6,4]
输出：5
```
**解释:** 在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

## 示例 2：

```
输入：prices = [7,6,4,3,1]
输出：0
```
**解释:** 在这种情况下, 没有交易完成, 所以最大利润为 0。

## 提示：
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

# 我的思路

贪心最小买入，最大卖出

一直替换``in``，当前比之前小，之后卖出肯定更大

为了不错过前面利润最大值，维护``res``最大利润

**比如下面例子**
```
输入: prices = [9, 18, 1, 0]
输出: 9
如果不记录可能输出0
```
## 小错误

```
int in = prices[0];
for (int i = 1; i < prices.size(); ++i)
{
    int out = prices[i];
    in = std::min(in, out);
    res = std::max(res, out-in);
}
```

外部的``in``被我定义成了局部变量

像这样
```
int in = prices[0];
for (int i = 1; i < prices.size(); ++i)
{
    int out = prices[i];
    int in = std::min(in, out); // ❌ 错误：新局部变量，遮蔽了外部的 in
    res = std::max(res, out-in);
}
```
